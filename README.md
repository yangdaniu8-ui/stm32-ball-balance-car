# 车载平衡滚球运动控制系统（电赛 H 题）

基于 **STM32F103C8T6** 的两轮差速智能小车 + 车顶摆杆钢球平衡系统。

- **下位机**：STM32F103C8T6 裸机（Keil MDK-ARM 工程），完成四路红外循迹、TB6612 电机驱动、MG996R 舵机摆杆平衡、OLED 显示与按键交互；
- **视觉**：K230D 端侧 AI（YOLO26n 目标检测），识别钢球并通过串口把其在摆杆上的横向位置（cm）实时发给主控；
- **算法**：PD 巡线控制 + **串级 PID**（位置外环→速度内环→舵机角度）实现小车行驶中钢球的动态平衡。

覆盖电赛 H 题全部赛题模式：单车巡线、钢球静止往返、AB 段行驶 + 球平衡、整圈行驶 + 球平衡、以及球停在任意指定位置。

## 二、赛题模式（MODE 键切换，共 5 个）

| MODE | 对应赛题 | 功能 |
|---|---|---|
| 0 | 要求2 | 单车循迹一圈自动停车计时（≤20s，停车偏差 ≤2cm） |
| 1 | 要求3 | 静止钢球往返 `0 → +5cm → -5cm`（≤5s，定位误差 ≤1cm） |
| 2 | 要求4 | A→B 直线行驶 + 钢球平衡（≤8s，球偏差 ≤1cm） |
| 3 | 要求5 | 整圈循迹 + 钢球平衡（≤30s） |
| 4 | 要求6 | 整圈循迹 + 钢球停在**任意指定位置**（±10cm 可调，误差 ≤1cm） |

## 三、操作说明

| 按键 | IDLE（待机） | RUNNING（运行中） | 其他 |
|---|---|---|---|
| **START** 短按 | 进入 3s 倒计时后启动 | — | FINISHED 时短按回到 IDLE |
| **START** 长按 | — | 紧急停车回 IDLE | 校准界面短按保存退出 |
| **MODE** 短按 | 循环切换模式 0→4 | — | |
| **MODE** 长按 | 进入舵机中点校准 | — | 显示当前 PWM 值 |
| **UP / DOWN** | MODE 0~3：调速 ±100；MODE 4：调整球目标位置（短按 ±1.0cm / 长按 ±0.5cm，限幅 ±10cm） | — | 校准界面下 ±10 / ±5 调中点 PWM |

启动后前 **3s 车速从 0 线性缓升**到设定值，避免起步加速度把钢球甩倒。

## 四、软件架构与算法

```
while(1) 主循环（裸机状态机）
 ├─ IDLE → COUNTDOWN(3s) → RUNNING → FINISHED
 ├─ 巡线 PD：四路加权误差 + 微分滤波 + 输出 EMA 平滑
 ├─ 球平衡：串级 PID（仅 RUNNING 且 MODE≥1 时运行）
 │   位置外环: (目标 - 滤波后位置) → 期望速度  cm/s
 │   速度内环: (期望速度 - 实测速度) → 舵机角度 (°)
 ├─ 速度估计：按 K230D 数据真实到达间隔微分 + EMA（20Hz 视觉）
 ├─ 补偿：起步加速度前馈 g_AccelFF、静摩擦助推、死区、
 │        积分限幅抗饱和、输出速率限制、舵机机械偏置
 └─ OLED 200ms 刷新（含 I2C 异常自动恢复）
```

核心文件：

- `USER/main.c` — 状态机、赛题模式调度、按键与 OLED
- `HAREWER/LINEWALKING/` — 四路循迹 PD 控制
- `HAREWER/BALANCE/` — 舵机 PWM + 串级球平衡 PID + K230D 串口解析
- `HAREWER/MOTO/` — TB6612 电机驱动（软启动斜坡）
- `HAREWER/OLED/` — SSD1306 驱动（I2C 自动恢复）
- `HAREWER/KEY/` — 按键扫描（短按/长按/连按）

### 串口协议（K230D → 主控）

115200-8N1，ASCII 一行一个数据，行尾 `\n`，数值为钢球相对摆杆中心的横向位置，单位 **cm**，约 20Hz：

```
-3.42
+1.05
```

> 主控侧用「收到新坐标的真实时间间隔」计算球速，而不是 1ms 循环节拍，避免 20Hz 视觉下的微分噪声。

## 五、编译 / 烧录

1. 用 **Keil MDK-ARM**（uVision 5）打开工程 `USER/AT8236.uvprojx`；
2. 工程已配置为标准外设库 + C8T6 启动文件，直接 **Rebuild**；
3. 用 ST-Link 烧录（工程 Output 目录为根目录 `OBJ/`，已加入 `.gitignore`）；
4. 首次上电建议先做 **舵机中点校准**：MODE 长按进入校准，UP/DOWN 把摆杆调到水平（默认 1800），START 短按退出。

### 配套要求

- K230D 端需单独烧录带 YOLO26n 钢球检测的固件，并把检测框中心换算成 cm 后按上述协议发送；
- 摆杆半长约 12.5cm，钢球识别区间对应舵机量程已做限幅。
